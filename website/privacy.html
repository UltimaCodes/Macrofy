Privacy

Last updated October 2026.

Short version: Macrofy runs on your PC, keeps your macros on your PC, and doesn't send anything about you or your typing anywhere.

What Macrofy sees

To turn one keyboard into a macro pad, Macrofy has to know which keyboard each key press comes from. While you're capturing a keyboard, it checks each key press as it happens: if it came from the captured keyboard, Macrofy stops it from typing and runs the macro you set up for that key. Key presses aren't recorded, logged or stored.

What Macrofy stores

Your profiles, keyboard names, layouts and settings are saved as files in %AppData%\Macrofy on your PC. If Macrofy crashes, it writes the error to log.txt in the same folder so you can share it if you choose. Nothing is uploaded.

What Macrofy sends

Only one thing: when it starts, an installed copy asks GitHub whether a newer version of Macrofy exists, and downloads it if you choose to update. GitHub sees that request like any web request (including your IP address); see GitHub's privacy statement. You can turn this off in Settings > Updates.

There is no analytics, tracking or account.

This website

This site doesn't use cookies or analytics. Fonts are loaded from Google Fonts and scripts from the jsDelivr CDN, which see standard request information. Downloads come from GitHub.

Questions

Open an issue on GitHub. The source code is public, so you can also check all of this yourself.
