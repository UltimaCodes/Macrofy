# Macrofy 1.2.0

The biggest update since 1.0. Macrofy got a new look, profiles you can put on any keyboard, an installer that keeps itself up to date, and a lot of work on the capture engine so it behaves.

## New

- **Profiles page.** Save a set of macros as a profile, then put it on any keyboard. Rename, duplicate, import and export them as files.
- **Templates for OBS Studio, Photoshop and VS Code** (15, 24 and 22 keys). Using one gives you your own copy to change however you want. OBS needs a one-time hotkey setup, and the card tells you how.
- **Every key shows what it does.** Bound keys on the on-screen keyboard show their action, so you can see your whole setup at a glance.
- **Pick a keyboard by pressing a key on it** instead of guessing which "HID Keyboard Device" is which.
- **Repeat while held**, for keys like volume, zoom and undo that should keep going while you hold them.
- **A real installer.** Download one `Macrofy-win-Setup.exe` (about 12 MB). It installs for your user account, so no admin prompt, and grabs the .NET 8 Desktop Runtime first if your PC doesn't have it. A portable zip is there too if you'd rather not install anything.
- **Updates itself.** When a new version is out, Macrofy tells you when it starts, and you install it from Settings in one click. You can turn the check off.
- **New look.** Sidebar with Keyboards, Profiles, Settings and About, a new logo, and a tray icon that shows when capture is on or something's wrong.
- **Show devices that aren't keyboards**, for macro pads and receivers that don't describe themselves as keyboards (Settings > Capture).

## Better

- Keys are tracked by their physical position, so your macros don't move around when you switch input language or toggle NumLock.
- Two identical keyboards plugged in at once stay separate, and Bluetooth keyboards are recognized properly.
- Macrofy notices keyboards being plugged in and unplugged. If you've set one to capture at startup, it grabs it again when it's plugged back in.
- Text macros type in one go, and line breaks and tabs come out as real Enter and Tab presses.
- Shortcuts with arrows, Home or End work with NumLock on, and more key names are understood, punctuation included.
- Apps open in their own folder, quoted paths and `%VARIABLES%` work, and apps you launch don't inherit Macrofy's admin rights.
- The keyboard hook only loads while a keyboard is captured, and unloads when you stop.
- If a macro fails, you get told instead of it failing silently.
- The "How to set it up" section on templates opens smoothly now.

## Fixed

- Macros re-firing on keyboard auto-repeat when they weren't meant to, and layer toggles flipping back and forth while held.
- A macro running twice if you pressed its key again before it finished.
- Pressing a key wiping out a macro you were still editing.
- Restored windows getting dragged off a second monitor.
- Learn keys getting messed up if capture or focus changed halfway through.
- Refresh and rename wiping the "Capture a keyboard at startup" setting.
- A missing or quarantined hook file crashing the app. It now shows a message instead.
- A profile that couldn't be read getting overwritten. It's moved aside now, and every save is written in one go so a crash can't leave half a file.

## Known issues

- **Running Macrofy as administrator** makes the captured key type in normal apps before the macro runs, so a key set to type "hello" gives you "xhello". Leave "Always run as administrator" off unless you need macros inside an app that itself runs as admin.
- **Some fullscreen games ignore capture completely**, because they read the keyboard directly instead of through normal Windows messages. There's no driver-free way around that, and Macrofy stays driver-free on purpose.
- The Windows keys can't be macros, some Microsoft Store apps (like Calculator) aren't covered, and virtual keyboards (remote desktop, virtual machines) don't work.
- The installer isn't code-signed yet, so Windows may show "Windows protected your PC" the first time. Click **More info**, then **Run anyway**.

## Coming from 1.0

Install 1.2 with the setup file. Your 1.0 profiles move into the new profile library the first time 1.2 starts, and they keep your keyboard's name. Once 1.2 is running you can delete whatever you downloaded for 1.0.
